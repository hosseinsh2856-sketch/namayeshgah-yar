نمایشگاه‌یار — نسخه نصب‌شونده موبایل

این نسخه PWA است و روی اندروید/آیفون می‌تواند مانند اپ به صفحه اصلی اضافه شود.

روش نصب:
1) فایل‌های این پوشه باید روی یک آدرس HTTPS قرار بگیرند.
2) در Chrome/مرورگر گوشی صفحه را باز کنید.
3) گزینه «Install app / افزودن به صفحه اصلی» را بزنید.
4) بعد از نصب، برنامه حتی برای ثبت اطلاعات به اینترنت نیاز ندارد.

نکته: اگر فقط index.html را مستقیماً از فایل‌منیجر باز کنید، ظاهر برنامه کار می‌کند، اما قابلیت نصب PWA ممکن است فعال نشود؛ برای نصب واقعی باید از HTTPS سرو شود.
